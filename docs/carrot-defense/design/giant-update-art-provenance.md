# Giant update: art provenance (characters stream)

Rule: generated images (image-model output) may ship only as textures or illustrations, and each one gets a row here.

| Shipped file | Use | Source master |
|---|---|---|

The characters stream shipped no image-model output. Every new texture is computed by `unity/CarrotDefense/Tools/bake_detail_normals.py` (hashes in `Assets/Resources/Carrot/Models/Materials/detail-normal-provenance.json`), every new mesh by the Blender scripts under `unity/CarrotDefense/Tools/`, and the portraits are renders of the game's own prefabs (`public/assets/minigames/carrot/portraits/portraits-provenance.json`). Licensed art (Asuna and the four effect packs) was never used as input to any of them.
