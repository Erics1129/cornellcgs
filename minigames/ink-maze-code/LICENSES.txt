Ink Maze code level — third-party licence notices
==================================================

The code level runs the player's program in the browser with language
toolchains compiled to WebAssembly. The big toolchains (the C/C++ compiler and
Python) load from a pinned CDN; the smaller runtimes are self-hosted under this
folder. The notices below cover both. This file is served alongside the
sandbox so the notices travel with the distributed code.

The Cornell CGS site's own code (everything under src/ and the sandbox host,
public/minigames/ink-maze-code/sandbox.html and sandbox.js) is the site's own
work and is not covered here.

Each self-hosted runtime's folder carries the full licence texts next to its
runtime.js, and every runtime folder has its exact build provenance
(PROVENANCE.txt). This file is the index. Self-hosted here: Java (~4.4 MB),
JavaScript (~0.57 MB), the Python and C/C++ glue (the site's own harness and
loader code, ~0.13 MB) and the sandbox host; Pyodide and the C/C++ compiler
load from the pinned CDN URLs below.
