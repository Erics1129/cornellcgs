Ink Maze code level — third-party licence notices
==================================================

The code level runs the player's program in the browser with language
toolchains compiled to WebAssembly. The big toolchains (the C/C++ compiler and
Python) load from a pinned CDN; the smaller runtimes are self-hosted under this
folder. The notices below cover both. This file is served alongside the
sandbox so the notices travel with the distributed code.

The Cornell CGS site's own code (everything under src/ and the sandbox host,
public/minigames/ink-maze-code/sandbox.html and sandbox.js) is the site's own
work and is not covered here.

Each runtime's own folder carries the full licence texts and the exact build
provenance (PROVENANCE.txt) once that runtime is added. This file is the index;
the per-runtime engineers fill in their section and drop the texts next to
their runtime.js.


Java  (public/minigames/ink-maze-code/java/, self-hosted, ~4.3 MB)
------------------------------------------------------------------
TeaVM-javac: OpenJDK's javac plus the TeaVM ahead-of-time compiler, both
compiled to WebAssembly.
  - TeaVM — Apache License 2.0.
  - OpenJDK javac (the compiler inside compiler.wasm) — GPL v2 with the
    Classpath Exception. The corresponding source offer and the exact build
    recipe go in java/PROVENANCE.txt.
Pinned build and hashes: java/PROVENANCE.txt.

-------------------------------------------------------------------------------

no acorn or other parser is used (QuickJS reports syntax errors itself).

Full text: javascript/LICENSE-quickjs.txt (both notices). Build and hashes:
javascript/PROVENANCE.txt.
