Third-party code inside the Java toolchain (besides TeaVM and OpenJDK)
======================================================================

TeaVM (Apache License 2.0, LICENSE-Apache-2.0.txt) depends on these
libraries, which it ships repackaged as teavm-relocated-libs-* 0.13.1 (HPPC
as org.teavm.hppc, Rhino as org.teavm.rhino). As far as its ahead-of-time
compiler reached them, they are compiled into compiler.wasm; JZlib is also
in runtime-classlib.bin (java.util.zip).
