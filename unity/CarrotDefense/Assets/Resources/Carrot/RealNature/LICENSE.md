# Scanned natural props — Poly Haven CC0

These assets are original Poly Haven scans, adapted for the Carrot Defense Unity runtime. [Poly Haven asset license](https://polyhaven.com/license) places their models and textures under CC0.

- [Shrub 02](https://polyhaven.com/a/shrub_02): Rico Cilliers. Three original variants arranged into one readable 1.71m clump: 18,020 triangles, one shared material.
- [Fern 02](https://polyhaven.com/a/fern_02): Rob Tuytel (scanning), Rico Cilliers (modeling). One 2,384-triangle clump retained.
- [Tree Stump 01](https://polyhaven.com/a/tree_stump_01): Rob Tuytel. Reduced from 41,046 to 7,970 triangles with original UVs.
- [Rock Moss Set 01](https://polyhaven.com/a/rock_moss_set_01): Kless Gyzen. Two silhouettes retained at 6,970 and 5,000 triangles.

Each prop uses one PBR material with 1024×1024 maps. Fern alpha is taken from the official opacity map. Texture channel packing changes data layout only. Official MD5 verification and local SHA256 hashes are recorded in source-provenance.json, mesh-provenance.json and texture-provenance.json.

Original source files live outside the Unity build in carrot-defense-preproduction/source-assets/polyhaven-models. No Poly Haven website preview renders are included.
